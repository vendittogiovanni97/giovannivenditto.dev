# Neural Field Explorer — R&D WebGPU Neural Rendering

## Il Contesto

Neural Radiance Fields (NeRF) e Gaussian Splatting hanno rivoluzionato la novel view synthesis. Tuttavia, l'esecuzione richiedeva tradizionalmente GPU server-side (CUDA) e streaming video. Con WebGPU e WebAssembly, oggi è possibile portare inference e rendering interamente client-side.

## Obiettivi della Ricerca

1. **Real-time Gaussian Splatting in browser**: Rendering 60fps di scene complesse (1M+ splats)
2. **NeRF inference client-side**: ONNX Runtime Web + quantizzazione INT8
3. **Progressive streaming**: Caricamento gerarchico per modelli >50MB
4. **Cross-platform**: WebGPU primary, WebGL 2 compute fallback, CPU fallback per compatibilità

## Innovazioni Tecniche

**1. Gaussian Splatting WebGPU-Optimized**
- Tile-based rasterization via compute shader (64x64 tiles)
- Parallel prefix sum (Blelloch scan) per depth sorting per-tile
- Spherical harmonics evaluation in-shader (SH degree 3)
- View-frustum culling su GPU (indirect draw)

**2. NeRF Inference Client-Side**
- Modelo TinyNeRF esportato ONNX, quantizzato INT8 (ONNX Runtime Web)
- Positional encoding precomputed in texture 3D
- Hierarchical sampling: coarse (64 samples) → fine (128 samples)
- Early termination via opacity threshold

**3. Progressive Streaming**
- Octree spatial partitioning
- LOD 0: bounding box → LOD 1: coarse splats → LOD N: full resolution
- Priority queue: viewport-proximity + screen-space error
- Service Worker + IndexedDB per caching persistente

## Risultati & Benchmark

- **Room** (240K splats): RTX 3080 120 fps / M2 Max 85 fps / iPhone 15 Pro 35 fps
- **Garden** (890K splats): RTX 3080 62 fps / M2 Max 42 fps / iPhone 15 Pro 18 fps
- **Museum** (1.2M splats): RTX 3080 48 fps / M2 Max 31 fps / iPhone 15 Pro 12 fps

**NeRF Inference (512x512, 192 samples/ray):**
- RTX 3080: ~8 fps (WebGPU compute)
- M2 Max: ~5 fps
- Fallback WebGL: ~2 fps
