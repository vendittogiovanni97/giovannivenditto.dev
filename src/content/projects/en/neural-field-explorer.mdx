# Neural Field Explorer — WebGPU Neural Rendering R&D

## Context

Neural Radiance Fields (NeRF) and Gaussian Splatting have revolutionized novel view synthesis. However, execution traditionally required server-side GPU (CUDA) and video streaming. With WebGPU and WebAssembly, it's now possible to bring inference and rendering entirely client-side.

## Research Goals

1. **Real-time Gaussian Splatting in browser**: 60fps rendering of complex scenes (1M+ splats)
2. **Client-side NeRF inference**: ONNX Runtime Web + INT8 quantization
3. **Progressive streaming**: Hierarchical loading for models >50MB
4. **Cross-platform**: WebGPU primary, WebGL 2 compute fallback, CPU fallback for compatibility

## Technical Innovations

**1. Gaussian Splatting WebGPU-Optimized**
- Tile-based rasterization via compute shader (64x64 tiles)
- Parallel prefix sum (Blelloch scan) for per-tile depth sorting
- Spherical harmonics evaluation in-shader (SH degree 3)
- View-frustum culling on GPU (indirect draw)

**2. NeRF Inference Client-Side**
- TinyNeRF model exported ONNX, INT8 quantized (ONNX Runtime Web)
- Positional encoding precomputed in 3D texture
- Hierarchical sampling: coarse (64 samples) → fine (128 samples)
- Early termination via opacity threshold

**3. Progressive Streaming**
- Octree spatial partitioning
- LOD 0: bounding box → LOD 1: coarse splats → LOD N: full resolution
- Priority queue: viewport-proximity + screen-space error
- Service Worker + IndexedDB for persistent caching

## Results & Benchmarks

- **Room** (240K splats): RTX 3080 120 fps / M2 Max 85 fps / iPhone 15 Pro 35 fps
- **Garden** (890K splats): RTX 3080 62 fps / M2 Max 42 fps / iPhone 15 Pro 18 fps
- **Museum** (1.2M splats): RTX 3080 48 fps / M2 Max 31 fps / iPhone 15 Pro 12 fps

**NeRF Inference (512x512, 192 samples/ray):**
- RTX 3080: ~8 fps (WebGPU compute)
- M2 Max: ~5 fps
- WebGL fallback: ~2 fps
