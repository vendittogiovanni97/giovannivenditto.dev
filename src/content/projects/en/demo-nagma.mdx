# Demo Nagma — Enterprise Tattoo Studio CRM

## Project Overview
**Demo Nagma** is an enterprise management platform (CRM) designed for comprehensive tattoo and piercing studio operations. It couples a Node.js 22+ & Express 5 REST API with **Prisma 7.8 / PostgreSQL 17** and a modern **Next.js 16 (App Router)** and **Material-UI (MUI)** frontend.

## Key Features & Architecture

### 📅 Agenda & Interactive Calendar
- Advanced calendar view (FullCalendar & AG Grid) with artist color coding, time slot management, and appointment statuses.
- Complete customer cards with medical notes/allergies, treatment history, and graphic drafts.

### 💰 Finance & Automated PDF Consent Forms
- Financial tracking of income, expenses, and payment methods with trend graphs.
- Automated generation of informed consent forms in PDF format via **PDFKit** and centralized report exports in **Excel (.xlsx)** and **CSV**.

### ⚙️ Monorepo & Docker Pipeline
- Monorepo architecture orchestrated with npm workspaces, Docker Compose for PostgreSQL 17, and test suites in Jest and Playwright.
