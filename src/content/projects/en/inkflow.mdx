# InkFlow - Tattoo Studio Management

## The Problem

Tattoo studios manage everything on paper, WhatsApp, Excel: appointment calendar, client files, informed consent, material inventory, payments, artist commission splits. No Italian vertical software solves the problem end-to-end. Generic tools (Calendly, Square, etc.) don't cover: medical-aesthetic informed consent, artist management with portfolio, ink inventory with batches/expirations, studio/artist payment splits.

## The Solution

Developed as a vertical SaaS product (B2B2C), InkFlow digitizes the entire studio operation:

**Core Modules:**
- **Smart Calendar**: Multi-artist, multi-resource (stations, rooms), variable durations by tattoo type, walk-in queue, drag&drop, real-time sync on all devices
- **Client CRM & Portfolio**: Profiles, tattoo history (photos, notes, artist), preferences, allergies, versioned informed consent
- **Digital Consent Form**: Canvas signature (touch/mouse), timestamp, IP, blockchain hash (Anchor protocol) for non-repudiation, generated PDF archived GDPR-compliant
- **Inventory & Supply Chain**: Inks, needles, gloves, aftercare - batch tracking, expirations, reorder thresholds, suppliers
- **Payments & Payouts**: Stripe Connect - client pays (deposit/balance/tip), automatic artist payout (configurable percentage), platform fees, electronic invoicing SDI
- **Artist Portal**: Personal dashboard: calendar, clients, portfolio, earnings, statistics
- **Studio Analytics**: Station occupancy, revenue per artist/service, client retention, conversion funnel

## Technical Architecture

```
┌─────────────────────────────────────────────────────────────────┐
│                        Next.js 13/14                            │
├──────────────────┬──────────────────┬──────────────────────────┤
│  App Router      │  API Routes      │  Middleware              │
│  (RSC, Layouts)  │  (webhooks,      │  (auth, i18n,          │
│                  │   Stripe,        │   feature flags)        │
│                  │   Supabase)      │                          │
└────────┬─────────┴────────┬─────────┴───────────┬──────────────┘
         │                  │                     │
    ┌────▼────┐       ┌─────▼────┐          ┌─────▼────┐
    │Supabase │◄─────►│  Prisma  │          │  Stripe  │
    │(Auth,   │       │ (Schema) │          │ Connect  │
    │ Realtime,│       │          │          │ (Payouts)│
    │ Storage) │       │          │          │          │
    └─────────┘       └──────────┘          └──────────┘
```

**Key Decisions:**
- **Supabase as unified backend**: Auth (email/password, magic link, OAuth), Database (PostgreSQL + RLS), Realtime (calendar sync), Storage (tattoo photos, consent PDFs) - zero server management
- **Row Level Security (RLS)**: Policy per tenant (studio) - native data isolation at DB level
- **Stripe Connect Standard**: Guided artist onboarding, automatic daily payouts, dispute/refund management
- **App Router Migration**: Feature flag per route, parallel run, automated testing (Playwright), instant rollback

## Full Stack

**Frontend:** Next.js 16, React 18, TypeScript, Tailwind CSS, Framer Motion, React Big Calendar, React Hook Form, Zod, date-fns, Lucide React
**Backend:** Supabase (PostgreSQL, Auth, Realtime, Storage, Edge Functions), Prisma ORM, Stripe Connect, Resend (email), Twilio (WhatsApp/SMS)
**Infrastructure:** Vercel (deploy, edge, analytics), GitHub Actions (CI/CD), Sentry (error tracking), PostHog (product analytics)
**Quality:** TypeScript strict, ESLint, Prettier, Husky, Playwright (e2e multi-browser), Vitest, Storybook
**Compliance:** GDPR (data export/deletion, consent log), eIDAS (advanced electronic signature), Electronic invoicing SDI
