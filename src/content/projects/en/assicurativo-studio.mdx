# Portale Assicurativo — Enterprise Management & OCR Pipeline

## Project Overview
**Portale Assicurazioni** is an enterprise platform designed to digitalize the management of insurance clients, contracts, and expirations. The app combines a ultra-reactive frontend built with **React 19 + Vite + Material UI** with a Node.js/Express backend and **MongoDB**.

## Technical Highlights & Features

### 🔍 Real-Time Watcher & OCR + LLM Pipeline
- **Real-Time Directory Monitoring**: Backend watches input folders in real-time via *Chokidar watcher*.
- **Automated Data Extraction**: Uploaded PDF policy documents are parsed using a combined **OCR (Tesseract)** and **LLM (Gemini)** pipeline to automatically extract client info, limits, premiums, and expiration dates.

### 🛡️ Security Hardening
- **IDOR Protection & RBAC**: Role-based access control (`admin`, `super_admin`) with ownership verification on sensitive attachments and resources.
- **MIME Magic Bytes Verification**: Binary signature inspection for image and PDF uploads to prevent malicious file execution.
- **Path Traversal Mitigation**: Controlled path resolution with strict system whitelisting.

### 📊 Analytics Dashboard & AG Grid
- High-performance tabular data management with **AG Grid 32** for fast search, advanced filtering, and report export.
