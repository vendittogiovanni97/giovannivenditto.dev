# Assicurativo Studio Platform

## The Problem

Italian insurance agencies still operate with largely manual processes: Excel spreadsheets for quotes, paper for policies, fragmented communication via email/WhatsApp. IVASS regulations require complete traceability, digital preservation, periodic reporting. Legacy software on the market is outdated, expensive, and non-integrable.

## The Solution

I led the end-to-end development of a SaaS platform that digitizes the entire lifecycle of an insurance agency:

**Core Modules:**
- **Smart Quoter**: Multi-step wizard with real-time premium calculation, company comparison, branded PDF generation
- **Policy Management**: Complete CRUD, automatic expirations, renewals, integrated claims management
- **Client CRM**: Profiles, interaction history, documents, omnichannel communication (email, SMS, PEC)
- **Regulatory Reporting**: IVASS exports, electronic invoicing SDI, compliant digital preservation
- **Back-office Collaboration**: Real-time presence, task assignment, complete audit trail

## Technical Architecture

```
┌─────────────────────────────────────────────────────────────┐
│                      Next.js 16 App Router                  │
├─────────────────┬─────────────────┬─────────────────────────┤
│  Server Comp.   │  Client Comp.   │      Edge/Serverless    │
│  (RSC default)  │  (interactivity)│   (auth, webhooks)      │
└────────┬────────┴────────┬────────┴───────────┬────────────┘
         │                 │                    │
    ┌────▼────┐      ┌─────▼────┐         ┌─────▼────┐
    │  tRPC   │◄────►│  Prisma  │         │  NextAuth│
    │  Router │      │  (Postgres)        │  (JWT)   │
    └─────────┘      └──────────┘         └──────────┘
```

**Key Decisions:**
- **tRPC + Prisma**: End-to-end type-safety without code generation. Safe refactoring.
- **Server Components by default**: Reduces client bundle by 60%, improves SEO and TTFB.
- **Internal Design System**: 60+ components, centralized tokens, Storybook, visual tests.
- **Web Workers**: Actuarial calculations (premiums, reserves) off-main-thread.

## Measurable Results

- **Quoting time**: 45 min → 12 min (**−73%**)
- **Manual data errors**: ~15% → <1% (**−93%**)
- **New agent onboarding**: 2 weeks → 2 days (**−85%**)
- **Client agency NPS**: 32 → 67 (**+109%**)

## Full Stack

**Frontend:** Next.js 16, React 18, TypeScript, Tailwind CSS, Framer Motion, Recharts, React Hook Form, Zod, date-fns
**Backend:** tRPC, Prisma ORM, PostgreSQL, NextAuth.js (JWT + email/password + magic link)
**Infrastructure:** Vercel (edge functions, ISR, image optimization), Upstash Redis (rate limiting, caching), Resend (transactional emails)
**Quality:** ESLint, Prettier, TypeScript strict, Husky, lint-staged, Playwright (e2e), Vitest (unit), Storybook (component docs)
**Monitoring:** Vercel Analytics, Sentry (error tracking), custom business metrics dashboard
