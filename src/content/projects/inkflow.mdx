# InkFlow - Gestionale per Studi Tatuaggi

## Il Problema

Gli studi tatuaggi gestiscono tutto su carta, WhatsApp, fogli Excel: agenda appuntamenti, schede clienti, consenso informato, inventory materiali, pagamenti, split commissioni artisti. Nessun software verticale italiano risolve il problema end-to-end. Gli strumenti generici (Calendly, Square, ecc.) non coprono: consenso informato medico-estetico, gestione artisti con portfolio, inventory inchiostri con lotti/scadenze, split pagamenti studio/artista.

## La Soluzione

Sviluppato come prodotto SaaS verticale (B2B2C), InkFlow digitalizza l'intera operatività dello studio:

**Moduli Core:**
- **Smart Calendar**: Multi-artista, multi-risorsa (postazioni, sale), durate variabili per tipologia tatuaggio, walk-in queue, drag&drop, sync real-time su tutti i device
- **Client CRM & Portfolio**: Anagrafiche, storico tatuaggi (foto, note, artista), preferenze, allergie, consenso informato versionato
- **Digital Consent Form**: Firma su canvas (touch/mouse), timestamp, IP, hash su blockchain (Anchor protocol) per non ripudiabilità, PDF generato e archiviato a norma GDPR
- **Inventory & Supply Chain**: Inchiostri, aghi, guanti, aftercare - tracking lotti, scadenze, soglie riordino, fornitori
- **Payments & Payouts**: Stripe Connect - cliente paga (acconto/saldo/tip), payout automatico ad artista (percentuale configurabile), fee piattaforma, fatturazione elettronica SDI
- **Artist Portal**: Dashboard personale: agenda, clienti, portfolio, guadagni, statistiche
- **Studio Analytics**: Occupazione postazioni, revenue per artista/servizio, retention clienti, conversion funnel

## Architettura Tecnica

```
┌─────────────────────────────────────────────────────────────────┐
│                        Next.js 13/14                            │
├──────────────────┬──────────────────┬──────────────────────────┤
│  App Router      │  API Routes      │  Middleware              │
│  (RSC, Layouts)  │  (webhooks,      │  (auth, i18n,          │
│                  │   Stripe,        │   feature flags)        │
│                  │   Supabase)      │                          │
└────────┬─────────┴────────┬─────────┴───────────┬──────────────┘

    ┌────▼────┐       ┌─────▼────┐          ┌─────▼────┐
    │Supabase │◄─────►│  Prisma  │          │  Stripe  │
    │(Auth,   │       │ (Schema) │          │ Connect  │
    │ Realtime,│       │          │          │ (Payouts)│
    │ Storage) │       │          │          │          │
    └─────────┘       └──────────┘          └──────────┘
```

**Decisioni Chiave:**
- **Supabase come backend unificato**: Auth (email/password, magic link, OAuth), Database (PostgreSQL + RLS), Realtime (calendar sync), Storage (foto tatuaggi, PDF consenso) - zero server management
- **Row Level Security (RLS)**: Policy per tenant (studio) - isolamento dati nativo a livello DB
- **Stripe Connect Standard**: Onboarding artisti guidato, payout automatici giornalieri, gestione dispute/rimborsi
- **Migration App Router**: Feature flag per route, parallel run, testing automatizzato (Playwright), rollback istantaneo

**Frontend:** Next.js 16, React 18, TypeScript, Tailwind CSS, Framer Motion, React Big Calendar, React Hook Form, Zod, date-fns, Lucide React
**Backend:** Supabase (PostgreSQL, Auth, Realtime, Storage, Edge Functions), Prisma ORM, Stripe Connect, Resend (email), Twilio (WhatsApp/SMS)
**Infrastructure:** Vercel (deploy, edge, analytics), GitHub Actions (CI/CD), Sentry (error tracking), PostHog (product analytics)
**Quality:** TypeScript strict, ESLint, Prettier, Husky, Playwright (e2e multi-browser), Vitest, Storybook
**Compliance:** GDPR (data export/deletion, consent log), eIDAS (firma elettronica avanzata), Fatturazione elettronica SDI
