# UI/UX Pro Max Skill Configuration

This project is configured with the **UI/UX Pro Max Design Intelligence Skill**.

## Search Tool Usage
To query design recommendations, run:
```bash
python3 .ui-ux-pro-max-skill/src/ui-ux-pro-max/scripts/search.py "<query>" [--domain <domain>] [--stack nextjs] [--design-system] [--variance <1-10>] [--motion <1-10>]
```

## Applied Design System: Aurora Kinetic Cyber-Minimalism
- **Primary Canvas**: Obsidian `#090d16`
- **Surface Panels**: Glassmorphic `#0e141a` with 1px `rgba(0, 240, 255, 0.12)` border and 16px backdrop blur
- **Accents**: Cyan `#00f0ff`, Violet `#8b5cf6`, Cobalt `#3b82f6`
- **Typography**: Space Grotesk / Geist for headlines, JetBrains Mono for technical labels
- **Interactivity**: 3D Tilt cards, cursor spotlight overlays, quick-view modals, kinetic typing, animated metric counters
